# Спрайты героя — промпты для ChatGPT

## Шаг 0. Эталон персонажа (один раз)
> Нарисуй персонажа для 2D-игры. Простой человечек-стикмен: круглая голова без лица, только две точки-глаза; тело, руки и ноги — одной линией. Рисованная тушью линия неровной толщины, слегка дрожащая, как от руки на бумаге. Цвет линии — тёплый светло-серый, почти белый (#e8e4dc). Голова чуть крупнее обычного, руки длинные и тонкие. Стоит прямо, вид сбоку в три четверти. Прозрачный фон, без теней, без земли, без текста. Квадрат 1024×1024, персонаж по центру, занимает ~80% высоты.

Сохрани удачный вариант как `hero-ref.png`. Дальше прикладывай его к каждому запросу.

## Шаг 1. Лента кадров (по одному состоянию на запрос)
Шаблон:
> Используя приложенного персонажа как эталон (тот же стиль линии, пропорции, цвет #e8e4dc), нарисуй спрайт-ленту для анимации «{СОСТОЯНИЕ}»: {N} кадров в один горизонтальный ряд, все одного размера, без промежутков и рамок. Персонаж в каждом кадре одного размера, ноги на одной линии внизу, по центру кадра. Кадры — последовательные фазы движения, последний плавно переходит в первый. Прозрачный фон, без теней, без текста, без номеров кадров. Итоговое изображение {N×256}×256 (или крупнее с тем же соотношением {N}:1).

Подставляй состояния:

| state | N | Описание движения |
|---|---|---|
| idle | 4 | стоит, медленно дышит: плечи чуть поднимаются и опускаются, на 3-м кадре моргает |
| climb | 6 | лезет вверх по отвесной стене, вид сбоку: руки и ноги поочерёдно перехватывают выступы |
| slip | 4 | соскальзывает: руки хватают воздух, тело сползает вниз |
| hold | 4 | висит на одной вытянутой вверх руке (его держат сверху), ноги покачиваются |
| breathe | 4 | стоит, глубокий вдох и выдох: грудь расширяется, голова приподнимается |
| fly | 6 | машет крыльями: на спине большие птичьи крылья, нарисованные той же линией; полный цикл взмаха |
| hang | 4 | висит на краю на двух руках, ноги свободно болтаются |
| letgo | 5 | висит на двух руках → пальцы раскрываются → отпускает и падает вниз, раскинув руки |

## Советы
- Крылья ChatGPT может нарисовать фотографически — тем лучше: по стилю они должны быть коллажной вырезкой. Тогда проси: «крылья — ч/б фото-вырезка настоящего птичьего крыла с белой обводкой, тело — рисованная линия».
- Если кадры получились разного размера или «уплыли», ничего страшного. Закинь их Claude Code: пусть скрипт нарежет их по сетке и выровняет по линии ног (`npm run sprites:normalize`).
- Плохой кадр проще перегенерировать отдельно: «перерисуй только кадр 3 из этой ленты, остальное не трогай».
- Не называй в промптах чужих персонажей и комиксы — нужен свой человечек.
