# Let me out — задание для Claude Code

## Что строим
Интерактивную историю в браузере «Let me out», 10–15 минут. Нарисованный человечек поднимается снизу вверх по этажам ямы (0–8), на некоторых этажах — мини-игры. Финал — стекло и просьба «отпусти». После финала начинается второй круг: герой помнит первый. Тезис: абсолютная свобода невозможна, потому что даже отношение человека к ограничениям чем-то обусловлено. Читатель — тот самый «ты», который смотрит сверху. Проигрыша нет.

Тексты всех этажей, реплик, сайд-сцен S1–S12 и мини-игр лежат в `docs/text-v2.md` (я положу его туда). Ничего не сочиняй вместо них. Если текста не хватает, оставь `TODO:` и скажи мне.

## Стек и ограничения
- Vite + vanilla TypeScript, без фреймворка. Сцена — DOM + inline SVG, а Canvas только для тумана и частиц, если без него никак.
- Анимации — CSS и Web Animations API; GSAP допустим, если очень нужен.
- Сборка — статичный `dist/`, деплой на GitHub Pages или Netlify. Сайт должен открываться из России без VPN и без авторизации.
- Внешних запросов во время работы нет: шрифты (Neucha, Caveat, JetBrains Mono — все с кириллицей) и картинки лежат локально.
- Начальная загрузка JS — не больше 150 КБ gzip, картинки — WebP с ленивой загрузкой по этажам.

## Визуальный стиль: Limbo + затемнённый коллаж + полукомикс
Правило: **живое нарисовано, вещи вырезаны из фото, мир — силуэт.**

Слои сцены, сзади вперёд:
1. Фон и туман: градиент `#0b0b0c → #1a1a1c`, зерно плёнки 6–10% (SVG feTurbulence или PNG-тайл), 2–3 медленных слоя тумана.
2. Мир-силуэт: стены, уступы и балки залиты `#050505`, края слегка неровные, без деталей.
3. Коллаж: вырезки из фото в PNG/WebP с альфой, ч/б и затемнённые (`filter: grayscale(1) brightness(.6) contrast(1.1)`), белая «ножничная» обводка 2–3 px (`drop-shadow` или обводка в самом ассете), лёгкий поворот ±3°.
4. Персонаж и живые существа (птица, улитка): inline SVG, линия `#e8e4dc`, «кипящая» линия — 2–3 варианта пути, смена на 6–8 fps.
5. Комикс-слой: реплики в рукописных облачках (Neucha 20–22 px) с хвостиком к говорящему.
6. Свет: одно тёплое пятно `#f2e6c9`, сделанное радиальной маской (`mask-image`) или `mix-blend-mode: soft-light`. Оно ведёт взгляд. Всё остальное в тени.

Акцентный цвет — ржавый `#a5543a`, не больше одного на экран. Контраст текста — не ниже 7:1, интерфейса — не ниже 4.5:1.

**Цитаты философов — надписи на стенах.**
- Компонент `<WallQuote>`: рукописный шрифт Caveat 22–32 px, у каждой надписи свой наклон от −8 до +6°, толщина неравномерная, есть подтёк или зачёркнутое слово.
- Подпись мелко: «— Сартр».
- Это настоящий текст, а не картинка.
- Надпись проявляется, когда до неё доходит свет. На экране — не больше одной.
- Данные лежат в `quotes.json` с полями `text`, `author`, `source`, `translator`, `page`.
- Без заполненного `source` цитату не показывать — пусть сборка падает с ошибкой.

**Комната (этаж 3) — главный коллажный экран.**
- 8–10 вещей-вырезок: стул, стол, лампа, шкаф, кровать, часы, ковёр, окно.
- Каждая вещь — `<button>` с `aria-label` вида «стул — убрать».
- Клик, тап, Enter или пробел — вещь исчезает:
  - секунду подрагивает;
  - теряет обводку;
  - рассыпается на 8–12 бумажных клочков (clip-path полигоны того же изображения), клочки гаснут;
  - всё вместе ~600 мс.
- Под вещью остаётся светлое пятно-силуэт.
- При reduced motion — просто fade за 200 мс.
- Есть кнопка «вернуть всё».
- Когда вещей не остаётся, срабатывает реплика героя из текста.

## Персонаж: анимированные спрайты
Человечек анимирован в каждом состоянии. Спрайты рисую я отдельно, в ChatGPT.

**Формат спрайтов:**
- Файлы `assets/hero/<state>.png` (и `.webp`). Это горизонтальная лента кадров на прозрачном фоне.
- Кадр 256×256, персонаж стоит ногами на одной линии (y=236) и по центру по x.
- Количество кадров и fps лежат в `data/hero.json`:
  ```
  { "idle": {"frames": 4, "fps": 6, "loop": true}, "climb": {"frames": 6, "fps": 10, "loop": true}, … }
  ```
- Состояния: idle, climb, slip, hold, breathe, fly, ghost, hang, letgo.

**Как проигрывать:**
- `background-position` + `animation: steps(N)` на `<div class="hero">`.
- Смена состояния — через `hero.set(state)`.
- Переходы мгновенные, без твинов: для покадровой рисованной анимации это нормально.
- Отражение по x (`scaleX(-1)`) — для движения влево.
- ghost = спрайт idle/fly с `opacity .5` и пунктирным эффектом (SVG-фильтр). Отдельный файл для него не обязателен.
- При reduced motion показывается только первый кадр состояния.

**Пока спрайтов нет:**
- Сделай заглушки — простой стикмен в inline SVG с 2–4 кадрами на состояние.
- Скрипт `npm run sprites:check` проверяет, что ширина каждого PNG равна `frames × 256`, и пишет, каких файлов не хватает.
- Скрипт `npm run sprites:normalize` (Node + sharp) берёт сырую ленту из `raw/hero/<state>.png`, режет её на N кадров, обрезает прозрачные поля, масштабирует до общей высоты персонажа, выравнивает по линии ног и центру и собирает ленту `frames × 256`. Он нужен, потому что ChatGPT отдаёт кадры неровно.

## Архитектура
```
src/
  main.ts            — запуск, роутинг этажей
  state.ts           — стейт-машина: floor, phase (enter|play|stop|exit), lap (1|2), seenScenes
  floors/            — по модулю на этаж, общий интерфейс Floor { mount, start, stop, unmount }
  games/             — hold.ts, breathe.ts, remove.ts, flap.ts, ghost.ts, letgo.ts
  hero/              — hero.svg.ts, состояния idle|climb|slip|hold|breathe|fly|ghost|hang|letgo
  scenes/            — sideScenes.ts (движок S1–S12)
  ui/                — ExitButton, SpeechBubble, WallQuote, Footnote, Credits
  input.ts           — единый ввод: pointer, touch, keyboard → действия
  a11y.ts            — reduced motion, live-области, фокус
data/
  floors.json, scenes.json, quotes.json, credits.json
assets/collage/, assets/textures/
```
- Тексты не хардкодятся в коде — всё берётся из JSON.
- Скролл не управляет сценой. Переход между этажами — явное действие («выше ↑», свайп вверх, стрелка ↑ или PageUp), плюс камера плавно едет вверх.

## Мини-игры: ввод и альтернативы
| Игра | Мышь / тач | Клавиатура | Альтернатива без удержания |
|---|---|---|---|
| Держи (этажи 1 и 7) | удерживать указатель на руке | держать пробел | кнопка-переключатель «держать / не держать» |
| Вдох | нажать на грудь | пробел | ничего не нажимать: через ~6 с дыхание включается само |
| Убрать | клик по вещи | Tab + Enter | — |
| Взмах | тап по левой или правой зоне | ← / → или A / D | кнопки «взмах влево / вправо»; в горле — «сложить / снять» |
| Без тела | drag призрака | стрелки | тап в точку — призрак плывёт туда; кнопка «вернуться в тело» |
| Отпусти | отпустить удержание | отпустить пробел | кнопка «отпустить» |

Общие правила для всех игр:
- Проигрыша нет. Бездействие ничем не грозит, через 20 с появляется мягкая подсказка.
- Нет hover-зависимостей.
- Зоны тапа — не меньше 44×44 px.

## Сайд-сцены (движок)
- Показываются только в фазе `stop`, никогда во время `play`.
- Не больше одной на этаж, шанс 0.4.
- Каждая сцена — один раз за круг. Сцены-пары (`pairOf`) идут строго по порядку: вторая часть только после первой.
- Закрываются крестиком, Esc или сами через `4000 + 400 * слов` мс. Таймер стоит на паузе, пока на сцене фокус или наведение.
- Вход и выход — fade; при reduced motion — простое появление.
- Текст дублируется в `aria-live="polite"`.
- Рандом с сидом (`?seed=123` в URL), чтобы баги можно было воспроизвести.

## Второй круг
- После финала в `localStorage` записывается `lmo.lap=2`. Каждое чтение и запись — в try/catch, при ошибке состояние держится в памяти.
- На втором круге меняются реплики (`floors.json → lines.lap2`) и открывается часть сцен.
- В футере есть кнопка «начать с нуля» — она сбрасывает прогресс.

## Доступность и требования курса (критерии приёмки)
- [ ] Ширина 320 CSS px и масштаб 200% без горизонтального скролла и обрезанного текста.
- [ ] Всё проходится только клавиатурой, фокус виден (обводка `#f2e6c9` 2 px).
- [ ] Всё проходится только пальцем на iOS Safari и Android Chrome.
- [ ] `prefers-reduced-motion`: без параллакса, кипящей линии и рассыпания, туман статичен.
- [ ] Любое автодвижение дольше 5 с можно поставить на паузу (кнопка «пауза анимации» рядом с «уйти»).
- [ ] Кнопка «уйти» есть на каждом экране, всегда в одном углу. Ведёт на экран выхода с веб-рингом и кредитами.
- [ ] У каждой коллажной картинки есть осмысленный alt, у декоративных — `alt=""`.
- [ ] Веб-ринг: ссылки на предыдущую и следующую работу с названиями. Данные в `data/webring.json`, сейчас там заглушки.
- [ ] Страница кредитов собирается из `credits.json` и `quotes.json`.
- [ ] Lighthouse: Accessibility ≥ 95, Performance ≥ 80 на мобильном.
- [ ] Ни одной ошибки в консоли, сайт работает без сети после первой загрузки ассетов этажа.
