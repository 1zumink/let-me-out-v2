# Let me out

Интерактивная история в браузере: человечек поднимается из ямы — девять этажей (0–8) и три прохода между ними, финал — стекло экрана и «отпусти», потом второй круг, где герой помнит первый.

Текст истории — `Let me out — текст v2 подъём.pdf`, его извлечённая копия — `docs/text-v2.md`.

## Запуск

```sh
npm install
npm run dev        # http://localhost:5173
npm run build      # статичный dist/ (проверяет data/*.json, падает на цитате без source)
npm run preview    # посмотреть сборку
npm test           # vitest: стейт-машина, сид, сцены, хранилище, валидатор
```

Параметры URL:
- `?seed=123` — сид рандома (сайд-сцены, наклоны надписей, клочки), чтобы баги повторялись;
- `?floor=5` — начать с этажа 5 истории (0–8); первый экран при этом пропускается;
- `?motion=reduce` — режим reduced motion без настройки ОС.

## Где что лежит

- `data/passages.json` — пул вещей для проходов (банка, часы без стрелок, табличка, рисунок, корни, гнездо, перчатка) и реплика «Кто-то тут жил…». Маршрут круга собирает `src/route.ts`: этажи и тихий уступ на своих местах, между этажами 4–5 случайных проходов по одной вещи, в круге без повторов, на следующем круге сначала невиданные вещи. Сид — из `?seed=`.
- `data/floors.json` — девять этажей и тихий уступ: `kind` (floor / passage), игра, `params`, коллаж и реплики по моментам (`lines.lap1`, `lines.lap2` подменяет только то, что в нём есть). Реплика — строка (говорит герой) или `{ who, text, pale, small }`; « … » внутри строки — пауза между облачками, «…» отдельной строкой — тишина.
- `data/scenes.json` — сайд-сцены S1–S12: `where` (этажи, `p-ledge` или `passage` — любой случайный проход; проходу подходят и сцены этажа прямо под ним), `laps`, `pairOf` (+ `crossLap` — отзвук на втором круге, `soon` — на следующей остановке), `after`, `steps` с говорящими и кнопками (`choice`, `otherwise`).
- `data/quotes.json` — шесть сносок после этажей (надписи на стенах): пересказ, `author`, `by` («по Сартру»), `source`. Без `source` сборка падает.
- `data/ui.json` — первый экран, подписи кнопок, инструкции к играм (`instructions`, черновик — см. ниже).
- `data/credits.json`, `data/webring.json` — кредиты, источники, веб-ринг.
- Что второй круг помнит о первом (комната, крылья, банка из S3, увиденные сцены) — `localStorage` `lmo.memory`; круг — `lmo.lap`. «Начать с нуля» стирает оба.

## Спрайты героя

1. Сырые ленты из ChatGPT кладутся в `raw/hero/<state>.png`.
2. `npm run sprites:normalize` убирает нарисованную «шахматку», режет ленту на кадры (по связным компонентам, поэтому кадры могут стоять неровно), выравнивает героя и собирает `public/assets/hero/<state>.png|webp` — кадры 256×256, ноги на y=236. У висящих состояний (`"align": "top"` в `data/hero.json`) по линии y=16 выровнены руки.
3. `npm run sprites:check` проверяет ширину `frames × 256` и пишет, каких файлов не хватает. Если ленты нет, герой рисуется SVG-заглушкой.

## Коллаж и фактуры

Промпты для ChatGPT — в `docs/image-prompts.md` (вещи комнаты и проходов, носок, телефон, фактуры стен, ленты героя `sit`, `held`, `ghost`).

1. Картинки вещей кладутся в `raw/collage/<id>.png`, фактуры — в `raw/textures/<id>.jpg`.
2. `npm run collage:normalize` убирает фон (белый или «шахматку»), обрезает и сохраняет `public/assets/collage/<id>.webp`, сам переписывает пути в `data/*.json` с `.svg` на `.webp`. Фактуры уходят в `src/assets/textures/<id>.webp` — игра подхватывает только те, что лежат (стены, доски комнаты).
3. Пока картинок нет, работают SVG-заглушки. Ч/б, затемнение и белую обводку вырезкам даёт CSS.
