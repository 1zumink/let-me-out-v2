# Let me out

Интерактивная история в браузере: человечек поднимается из ямы — девять этажей (0–8) и три прохода между ними, финал — стекло экрана и «отпусти», потом второй круг, где герой помнит первый.

Текст истории — `Let me out — текст v2 подъём.pdf`, его извлечённая копия — `docs/text-v2.md`.

## Запуск

```sh
npm install
npm run dev        # http://localhost:5173
npm run build      # статичный dist/ (проверяет data/*.json, падает на цитате без source)
npm run preview    # посмотреть сборку
npm test           # vitest: стейт-машина, сид, сцены, хранилище, валидатор
```

Параметры URL:
- `?seed=123` — сид рандома (сайд-сцены, наклоны надписей, клочки), чтобы баги повторялись;
- `?floor=5` — начать с места 5 (0–11: 0 дно, 1 кольца, 2 руки, 3 дыхание, 4 корни, 5 комната, 6 Костя, 7 крылья, 8 уступ, 9 призрак, 10 свет, 11 край); первый экран при этом пропускается;
- `?motion=reduce` — режим reduced motion без настройки ОС.

## Где что лежит

- `data/floors.json` — двенадцать мест: `kind` (floor / passage), игра, `params`, коллаж и реплики по моментам (`lines.lap1`, `lines.lap2` подменяет только то, что в нём есть). Реплика — строка (говорит герой) или `{ who, text, pale, small }`; « … » внутри строки — пауза между облачками, «…» отдельной строкой — тишина.
- `data/scenes.json` — сайд-сцены S1–S12: `where` (места), `laps`, `pairOf` (+ `crossLap` — отзвук на втором круге, `soon` — на следующей остановке), `after`, `steps` с говорящими и кнопками (`choice`, `otherwise`).
- `data/quotes.json` — шесть сносок после этажей (надписи на стенах): пересказ, `author`, `by` («по Сартру»), `source`. Без `source` сборка падает.
- `data/ui.json` — первый экран, подписи кнопок, инструкции к играм (`instructions`, черновик — см. ниже).
- `data/credits.json`, `data/webring.json` — кредиты, источники, веб-ринг.
- Что второй круг помнит о первом (комната, крылья, банка из S3, увиденные сцены) — `localStorage` `lmo.memory`; круг — `lmo.lap`. «Начать с нуля» стирает оба.

## Спрайты героя

1. Сырые ленты из ChatGPT кладутся в `raw/hero/<state>.png`.
2. `npm run sprites:normalize` убирает нарисованную «шахматку», режет ленту на кадры (по связным компонентам, поэтому кадры могут стоять неровно), выравнивает героя и собирает `public/assets/hero/<state>.png|webp` — кадры 256×256, ноги на y=236. У висящих состояний (`"align": "top"` в `data/hero.json`) по линии y=16 выровнены руки.
3. `npm run sprites:check` проверяет ширину `frames × 256` и пишет, каких файлов не хватает. Если ленты нет, герой рисуется SVG-заглушкой.

## Коллаж

`public/assets/collage/*.svg` — временные вырезки-заглушки. Настоящие фото — WebP с альфой, тот же путь в `floors.json → collage[].src`. Ч/б, затемнение и белую обводку добавляет CSS.
