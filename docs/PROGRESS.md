# Let me out — где мы сейчас (сводка для продолжения)

Обновлено: 27.10.2026, после v1.4, читки и переделки движения (не закоммичено).

## Что это
Интерактивная история в браузере (Vite + vanilla TypeScript, без фреймворка).
- Человечек поднимается из ямы по 9 этажам; между ними тихий уступ и случайные проходы.
- Финал — стекло экрана и «отпусти». Потом второй круг, где герой помнит первый.
- Текст истории: `Let me out — текст v2 подъём.pdf` → извлечённая копия в `docs/text-v2.md` → реплики в `data/*.json`.
- Исходное ТЗ: `CLAUDE_CODE_PROMPT.md`; промпты спрайтов: `SPRITES_PROMPT.md`; промпты картинок: `docs/image-prompts.md`.

## Как запустить и проверить
```bash
npm install
npm run dev            # http://localhost:5173 (у нас часто 5179)
npm test               # vitest (сейчас 52 теста)
npm run build          # проверяет data/*.json, сборка в dist/
npm run sprites:normalize && npm run sprites:check   # ленты героя из raw/hero
npm run collage:normalize                            # вещи и фактуры из raw/collage, raw/textures
node scripts/sprites-normalize.mjs --still palm      # ладонь финала — линией героя, не фото-вырезкой
```
Параметры URL:
- `?seed=N` — сид случайностей;
- `?floor=N` — начать с этажа истории 0–8;
- `?motion=reduce` — режим без движения.

Как проверять в браузере (выученное на практике):
- **dev-страница перезагружается** при каждой правке файлов (особенно когда параллельно работают другие сессии). Для замеров — статичная сборка: `npx vite build --outDir /tmp/x && npx vite preview --outDir /tmp/x --port 4180`.
- **Встроенная панель браузера в скрытом виде останавливает `requestAnimationFrame`** — облачки и анимации стоят. Длинные прогоны — в Chrome (Claude in Chrome), вкладка на переднем плане.
- Автопрогон двух кругов: JS-кликер жмёт «выше», «держать / не держать», вещи комнаты, взмахи по очереди, «сложить», «дальше», «вернуться», «отпустить» и пишет лог из `.status` и live-области `[role=status]`.
- Пересечения зон нажатия в комнате проверялись на iframe-ах `flex:none` 320×600, 375×740, 412×780, 640×360, 740×360, 1000×700.
- Lighthouse: `npx -y lighthouse@12.6.0 <url> --form-factor=mobile --chrome-flags="--headless=new"`.
- Последние замеры: первый экран 100 / 100 / 100, комната Performance 85, Accessibility 100.

| `src/input.ts` | клавиши → действия, непрерывная прокрутка (колесо, трекпад, палец), `bindHold`, `bindPress` |

| `src/lines.ts` | реплики: « … » — пауза между облачками, `pickMoment` — второй круг подменяет первый |
| `src/hero/hero.ts` | герой: ленты кадров (WAAPI `steps`), один CSS-якорь (ноги), `place` / `put` / `toFeet`, `scrub(state, t)` — кадр по прокрутке, `go` / `walkTo` — перемещение шагом, `box()`, `data-strip` — какая лента играет; нет файла ленты — запасная из `FALLBACK` |

| `scripts/*` | `validate-data.mjs`, `sprites-normalize.mjs` / `sprites-check.mjs`, `collage-normalize.mjs` (убирает фон и тень, ≤ 480 px, переписывает пути в `data/*.json`) |

## Решения (не переигрывать без автора)
- Пластика: **коллаж** — фото-вырезки ч/б с белой обводкой, мир — тёмный силуэт с затемнённой фото-фактурой, живое нарисовано линией.
- **Прокрутка тянет подъём**; кнопка «выше» и стрелка — тот же путь.
- Проходы **случайные**: 4–5 за круг, одна вещь; **тихий уступ всегда перед призраком**.
- Сноски после этажей — **надписи на стенах** с подписью «— по Сартру» и т. п., источник по звёздочке.
- Тексты не сочиняем: чего нет в тексте — `TODO`. Исключение — инструкции к играм в `data/ui.json → instructions`: написаны Claude, помечены `_draft`.
- **Деплой — только по команде автора** (вариант: GitHub Pages через `gh`).
- Новых сцен не добавляем (просьба преподавателя), доводим существующее.
- **Герой движется только по стенам и уступам**: между местами — путь `climbPath`, внутри мест — `hero.go` / `walkTo`. CSS-перехода по `left/top` у `.hero` больше нет: `place()` ставит сразу, скольжение по воздуху запрещено. Склейки (новый круг, `?floor`) — из темноты.
- **Финал**: крупный план у стекла, ладонь к экрану на «Это стекло», отпустить — клик по герою (кнопка — с клавиатуры). Держание указателем убрано.
