# Картинки для ChatGPT — промпты

Правило мира: живое нарисовано линией, вещи — ч/б вырезки из фото с белой «ножничной» обводкой, мир — тёмный силуэт. Обводку, ч/б и тёмный тон в игре даёт CSS. Поэтому от ChatGPT нужны чистые фото предметов на ровном фоне, без рамок и эффектов.

✓ есть — нарисовано автором 27.10 и уже в игре: движение по стенам, финал у стекла, домик и бумага для сцен. Чтобы перерисовать что-то из этого, положи новый файл под тем же именем и запусти обработку (ниже).

Как просить: в начале чата один раз вставь **общий блок стиля**. Дальше в каждом запросе одна строка предмета. Если стиль поплыл, вставь блок ещё раз. Удачную картинку сохрани под именем из колонки «файл».

## Общий блок стиля (вещи)

> Документальная чёрно-белая фотография одного предмета, как из старого семейного архива или каталога. Предмет целиком в кадре, ничего не обрезано, вокруг поля примерно в 10% ширины. Фон ровный, чисто белый, без градиента, без пола, без горизонта. Тени на фон не падают, отражений нет. Вид чуть сверху и сбоку, примерно на три четверти. Свет мягкий, рассеянный, как у окна в пасмурный день. Плёночное зерно лёгкое, резкость нормальная. На предмете нет текста, логотипов и надписей, если в описании не сказано иначе. Без людей, без рук, без рамки и подписи. Квадрат 1024×1024.

Вместо прозрачного фона ChatGPT часто рисует серую шахматку. Скрипт её уберёт, но белый фон надёжнее, особенно для светлых предметов. Если картинка вышла цветной, ничего страшного: игра сама переводит в ч/б.

## Куда класть и что запускать

1. Вещи сохрани в `raw/collage/<id>.png` (подойдут `.jpg` и `.webp`), фактуры — в `raw/textures/<id>.jpg`, ленты героя — в `raw/hero/<state>.png`. Имена файлов как в таблицах выше.
2. Вещи и фактуры:
   ```bash
   npm run collage:normalize
   ```
   Можно только часть: `npm run collage:normalize -- cup clock`. Скрипт:
   - убирает фон заливкой от краёв;
   - обрезает по предмету и уменьшает до 480 px по длинной стороне;
   - кладёт `public/assets/collage/<id>.webp`;
   - в `data/*.json` меняет `assets/collage/<id>.svg` на `.webp`;
   - фактуры кладёт в `src/assets/textures/<id>.webp` — игра подхватит их сама.
3. Ленты героя:
   ```bash
   npm run sprites:normalize
   ```
4. Проверка и просмотр:
   ```bash
   npm run dev
   ```

Если фон съел светлый край предмета, причина обычно в серой шахматке: скрипт считает фоном всё светлее её тёмных клеток. Перегенерируй на белом фоне. Белое внутри предмета скрипт не трогает (лист календаря, циферблат, окошко у ручки чашки), потому что заливка идёт только от краёв картинки. Если такое окошко должно быть прозрачным, его придётся стереть вручную.
